Chest X‑Ray Disease Classification

Python TensorFlow / Keras Flask OpenCV DenseNet121

🎯 Problem Statement

Developing a deep learning web application to classify compressed chest X-ray images into four categories: COVID-19, Normal, Viral Pneumonia, and Lung Opacity. The project focuses on building an end-to-end pipeline from data preprocessing to model deployment, highlighting practical skills in computer vision and medical AI.

🧠 Methodology

  • Preprocessed and augmented a dataset of compressed chest X‑ray images.
  • Fine‑tuned a pre‑trained DenseNet121 convolutional neural network.
  • Achieved high validation accuracy through hyperparameter tuning.
  • Deployed via a Flask web app with real‑time image classification.
