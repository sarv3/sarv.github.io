Final Year Project

Chest X-Ray Disease Classification

A deep learning web application that classifies compressed chest X-ray images into four categories: COVID-19, Normal, Viral Pneumonia, and Lung Opacity.

Deep Learning Computer Vision Python TensorFlow / PyTorch Web App (Flask) Medical AI

Overview

This project leverages deep convolutional neural networks to analyze chest X-ray images and provide rapid, accurate classification of pulmonary diseases. The goal is to assist healthcare professionals in triaging patients and improving diagnostic efficiency, especially in resource-limited settings.

I developed the full pipeline: from data preprocessing and augmentation to model training, evaluation, and deployment as an interactive web application using Flask. The model was trained on a publicly available dataset of over 20,000 chest X-ray images.

🎯 Objectives

  • ▹ Build a multi-class classifier with high accuracy (>92%).
  • ▹ Implement real-time image preprocessing for compressed X-rays.
  • ▹ Deploy a user-friendly web interface for clinicians.
  • ▹ Ensure model interpretability with Grad-CAM visualizations.

Key Features

🧠

Advanced CNN Architecture

Custom ResNet-50 variant optimized for medical imaging with fine-tuned layers.

⚡

Real-time Inference

Processes uploaded images in under 2 seconds with confidence scores.

🔍

Explainable AI

Integrated Grad-CAM heatmaps to highlight regions influencing the prediction.

📊

Comprehensive Metrics

Displays accuracy, precision, recall, and F1-score per class after evaluation.

📱

Responsive Web App

Flask + Bootstrap frontend that works seamlessly on desktop and tablets.

📁

Batch Processing

Supports uploading multiple X-rays at once for bulk diagnosis.

Development Process

Data Collection & Preprocessing

Combined multiple public datasets (COVID-19 Radiography Database). Applied histogram equalization, resizing, and normalization.

Model Architecture Design

Experimented with VGG16, ResNet50, and DenseNet121. Selected ResNet50 with custom classification head.

Training & Evaluation

Trained on 80% of data, validated on 10%, tested on 10%. Achieved 94% test accuracy with weighted F1-score.

Web Application Development

Built a Flask API backend with an intuitive UI. Integrated model inference pipeline and result visualization.

Deployment & Testing

Containerized with Docker for reproducibility. Conducted user acceptance testing with medical students.
